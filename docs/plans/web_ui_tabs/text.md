# Replace Text tab (ns `text`) - web port status

Shown for Stern Spike 2 only (`capabilities.replace_text`; Spike 1, Whitestar and every other manufacturer hide it). The tab also carries the two tool windows it reaches: the Scenes window (`gui/scene_browser.py`, opened by "Show in Scenes…", the Images tab's Scenes… and the Video tab's Show scene contents…) and the Fonts window (`gui/font_studio.py`, reached from the Scenes window's font rows and the Images tab's Fonts…). The shell renders both windows over every tab.

## Files

- `pinball_decryptor/webui/tabs/text.py` - the tab service (`TextTab`).
- `pinball_decryptor/webui/text_rules.py` - the Tk tab's Tk-free rules moved out of `MainWindow` (Max, grows, budget readout, filters, Scene menu, Replace everywhere plan, the editor notes, the too-long message, and `pending_text_status` + its four wordings for the Write tab's pending list).
- `pinball_decryptor/webui/text_scenes.py` - the Scenes window, namespace `text_scenes`.
- `pinball_decryptor/webui/text_fonts.py` - the Fonts window, namespace `text_fonts`.
- `pinball_decryptor/webui/static/js/tabs/text.js`, `text_scenes.js` (`ScenesWindow`), `text_fonts.js` (`FontsWindow`, and the shared `ToolWindow` frame and `ToolDock`).
- `pinball_decryptor/webui/static/css/tabs/text.css`, `text_scenes.css`, `text_fonts.css` (the two window sheets are loaded by their own modules, so they are styled on every page; `text_fonts.css` also styles the `ToolWindow` frame and the dock).
- `tests/test_webui_text.py`.

## Ported (by Tk section)

Virtual table: 11 622 rows on the Godzilla project. A filter change resends only the visible order (indices); an edit patches only the rows it touched. Column edges drag; the widths are saved in settings.json under Tk's key and column ids (`column_widths["text"]`: `#0 / new / max / scene / name`), so widths saved by either version carry over. The Scene column (212 px) shows the whole `49ac2…71dd/scene.radium` label.
- Right-click menu: Edit…, Replace everywhere…, Show in Scenes…, Name this scene…, Revert this string (edited rows). Double-click / Enter focuses the editor; arrow keys move the selection.
- Editor: Original, New text, "N / M bytes" readout (red and Apply disabled when too long; "the scene is rewritten at the new length", "placed in a new area of the game program", "(not used by the game)"), "Apply to every scene with the same original text", Revert, Apply (and Enter), the scene / game-program note, the "Your edits are saved to text/strings.tsv…" note. The list takes what the page leaves and shrinks first (Tk packed the editor at a fixed height under it), so Apply stays in view; in a short window (below 760 px) the saved-to note moves onto an "i" by the byte count. Apply refuses a too-long edit with the Tk message; a save writes `text/strings.tsv`, calls `on_folder_state_written`, records `.history.log` and the log line, and redraws an open Scenes window.

- Window exports: the seven `text_*_var`s, `reveal_text_string`, `_open_scene_browser` (the Video tab's call), `open_scene_browser(assets, preselect_rel=…)` (the Images tab's call), `open_font_studio(assets, preselect=…, preselect_rel=…)` (the Images tab's call), `_open_font_studio`, `_scan_text_strings`, `_refresh_scene_browser_text`, `_text_rows`, `_text_scan_dir`. `text_grow_enabled` is the Write tab's (it owns `write_text_grow_var`).

The two tool windows (`ToolWindow`): Tk's were non-modal Toplevels, and so are these: nothing is dimmed and a click outside never closes them, so the rail, the tab under them and the other window stay usable (edit a line on the Replace Text tab and an open Scenes window redraws it). Both can be open at once; the one opened or clicked last is in front, and closing it shows the one under it (Scenes → font row → Fonts → Close lands back on Scenes, and the other way round). The title bar drags (zoom-aware), the corner sizes, and a window opened again comes back where it was left, all of it in view; the second window opens stepped down from the first. Escape closes the window that has the keyboard (Tk bound it on the Toplevel), never while a menu or a question is open over it: Escape on "Blank this font…?", "Revert font…?" or "Unapplied import" answers only the question. A jump to a tab (double-click an image, text line or video) steps BOTH windows aside, as Tk's `_step_aside_for_jump` lowered every tool window; nothing is closed or reset, and a button per window in the status bar (next to Log) brings it back, as do Show in Scenes… / Scenes… / Fonts…. Each window's title bar also has a Step aside button. Close starts the next open fresh, as Tk's destroyed window did.

Right-click a line: Text colour… (colour picker), Back to the original colour, Move… / Font size… (the fields sit in a strip right under the preview while the edit is live, so the preview they drive is never covered; Enter applies, Escape cancels; picking another scene cancels it), Alignment ▸ Left / Centre / Right (a cascade with the current one ticked, as Tk's), Back to the original layout, Find on the Replace Text tab. Right-click a font: blank in this scene / everywhere (asks first), Open in the Fonts window. A narrow window (below 1000 px of body) stacks the list over the contents and scrolls.

Fonts window (`FontStudioWindow`): hint (count, copies, old-extract note); Search; font list (Font / Size with NOT APPLIED / tiny / +outline / copy n of m marks / Chars / Scenes; the name takes most of the width, edges drag); Used in scenes with Change in all of them / only the scenes I select (click, Ctrl-click, Shift-click; persisted with `set_font_scope`), right-click a scene → Show "…" in Scenes… (opens it in front; this window stays open behind); Preview text (\n = new line), Zoom, Show (Current glyphs / Imported (preview)), Behind; the preview; the status line; Import a desktop font (Import font file…, Color + match original, Outline px + colour, the scene-tint note, Size %, Letter width %, the outline-companion note and Its outline: Remove / Leave); Also change the other N copies; Apply to this font (import or colour-only recolour; small-font question; companion scoping and blanking; every copy re-fitted), Undo (5 steps / 64 MB), Blank font, Revert font, Revert all fonts…; closing with an unapplied import asks first. ## Core requests

1. `dialogs.js` `MessageModal` / `PromptModal` answer Escape on the document without stopping it, so any core `Modal` under a Python question also closes on the same key. The tool windows no longer use `Modal` and check for an open question themselves, but other pages' dialogs can still hit it. Suggest: answer Escape in a capture-phase listener and `stopImmediatePropagation()`, or make `Modal` ignore Escape while `state.modals.open` is non-empty, and a core test with a `Modal` under a messagebox.
2. `ui.js` `Table` column resize mixes window px (`getBoundingClientRect`, `clientX`) with style px, so at a zoom other than 100 % a dragged column jumps by the zoom factor (the Audio tab divides by the zoom in its own grips). Suggest dividing both by `parseFloat(document.documentElement.style.zoom) || 1`.
3. `images.py`: own the scene-name hand-off as `ImagesTab.scene_names_changed(scan_dir, tags)` (same folder: `_group_tags = dict(tags)`, `_refresh_image_list()`). `text.py` calls it when it exists and until then sets those two attributes itself.
