## Owed

- Nothing the Tk tab did is missing. Differences by design: playback is the page's own player (no ffplay needed; a format it can't read is converted to WAV with ffmpeg for the preview, and without ffmpeg the "Can't Preview" box says so), the row list keeps its selection across filter changes (the Tk tree dropped it on every rebuild), and Shift+arrow extends the selection (Tk 8.6 moved). The Tk-tuned widths are reused as CSS pixels; the web table's font is a little wider than the Tk tree's, so a column dragged tight in Tk (Format at 151) can end in "…" (the full text is the cell's tooltip; drag it wider).
- Not exercised on real CGC / BOF / JJP / Spooky extracts: none are on this PC (the JJP and Spooky projects in settings.json are gone). Those plugins were checked on a scratch copy of Godzilla sounds (columns, gates, flags) and by the tests (CGC groups via a fake duplicate result).
- The "Tips - Audio" window is the shell's help menu ("Tips for this tab"), not this tab.
- A column drag at an app zoom other than 100% still jumps while the mouse is down (the core `Table`, core request 1); what it saves is right. At 100% it tracks the mouse.
- The fixes since the review were checked in Edge only, not re-run on WebKit / macOS.

## Core requests

Done in the framework since the first port: the `Button` accessible name, and `window.select_tab` stopping every preview (the tab's `audio.left` workaround is gone; it uses `on_tab_changed`).

Open (each worked around in this tab; other tabs hit them too):

1. `ui.js` `Table` resize ignores the app zoom: `startResize` measures `getBoundingClientRect()` (zoomed pixels) and lays the drag out as CSS pixels, so at 125% every column grows by the zoom the moment a grip is pressed, the dragged edge runs ahead of the mouse, and the widths `onResize` reports are zoomed. Audio divides by the zoom before saving (so what it saves is right), but the live drag still jumps and snaps back on release. Fix: divide the measured widths and the mouse delta by `parseFloat(document.documentElement.style.zoom) || 1`.
2. `app.css` `.col-grip::after` (top/bottom 8px) collapses to a dot because `.tbl .tr { align-items: center }` makes header cells only as tall as their text. Audio stretches its header cells (`align-self: stretch`). Fix: `.tbl .th > .c { align-self: stretch; display: flex; align-items: center; }` (or size the grip from the row).
3. `ui.js` `Table` keyboard: `onKey` looks the current row up by `selKey`, which is null whenever `selected` is a Set, so any multi-row selection arrows to row 0; and it has no focus row, so arrows after a Ctrl-click cannot move from the clicked row. Audio handles its own arrows in `onKeyDownCapture` (`keyNav`). Fix: a `cursor` / `focusKey` prop the Table's `onKey` moves from.
4. `webui/window.py` `last_browse_dir` returns a remembered folder without Tk's `os.path.isdir` check, so every tab's picker opens a deleted folder as "[WinError 3]" over an empty list; `remember_browse_dir` also keeps a folder that does not exist. Audio asks through its own `_ask_path` with the Tk rule.
5. `ui.js` `openMenu`: an item with `checked: false` draws an empty 14px slot, not a box. Audio sends "☐  " / "☑  " in the label (the Tk labels).
