# Replace Images tab (ns `images`): port status

Files: `pinball_decryptor/webui/tabs/images.py`, `webui/static/js/tabs/images.js`, `webui/static/css/tabs/images.css`, `tests/test_webui_images.py`.

Tk source: `gui/main_window.py` `_build_image_tab` (9209-9431) and the image methods (9431-10873), the shared Replace-tab helpers it calls (probe pass 4576, change scan 4806-5140, bulk clear and Replace from folder 8117-8660, scan buttons and scanning state 21103-21420, sidecar writer 11433), its part of `apply_manufacturer` (18270-18291).

`gui/image_table.py` is the Multi-boot tab's image table and `gui/preview_dialog.py` is Settings > Preview features. Neither is part of this tab.

The tab shows only where `capabilities.replace_image` is set. Today that is Stern Spike 2 only (Spike 1 and Whitestar do not set it, and no other plugin does). The tests check the gate for every manufacturer and every era.

## Ported (by Tk section)

- **Intro and Pillow banner**: the intro line is the page subtitle. The Pillow-missing note is re-checked on every visit (`on_show`). The words "above the tabs" were dropped because the web layout has no such place.
- **Project Folder row**: the project now shows in the shell's top bar, as in the design. Scan (it becomes "Cancel scan" while running), Replace from folder… and Clear replacements… are in the page head. The clear button greys out when there is nothing to clear or a run is going.
- **Scan**: runs on a worker thread and drops stale results with a bump counter. It uses the plugin's `image_slot_dirs` / `image_slot_exts` and parses the `scan_image_groups` manifests. It logs "Images scan started / finished in N s / cancelled after / replaced after". While it runs, the list is blank under a busy empty state. The tab re-scans when it is shown and the folder has changed (`_maybe_rescan_image`). The Pillow metadata probe is a worker pool drained on the UI loop, and it resends only the row chunks it touched.
- **Change-on-disk diff**: `checksums.changed_rels` plus `.orig` snapshots, and `folder_match.foreign_twins`. The status line shows the "  ·  still checking…" note while the diff runs. Stray files get "⚠ not on this card" and the two warning log lines. The Replacement pane's empty text covers each case: a changed slot with no snapshot, a stray file, or a file-type twin.
- **Toolbar**: Search (live, and it matches container labels, renames and key tails with the glyph rule). Source filter (All sources / File / Scene texture / Radium / Glyph / Boot screen). Show (All / Changed / Unchanged). Group by scene. Each keeps its Tk tooltip. Source, Show and Group are saved in the folder's sidecar, restored on scan, and read the old `image_changed_only` key too.
- **Table**: a thumbnail, Original Image, Images (grouped mode only), Resolution, Format, Source, Keep size (only when the scan has a Radium picture that is not a font atlas), and Replacement. Clicking a header sorts with Tk's default directions and ▲/▼. In grouped mode the header rows fold and unfold, children come in play order, and "Images" sorts the groups by count. Row colours follow the design: a pick is amber, changed on disk is blue ✓, not on this card is amber-warn. A click in the Replacement cell opens the picker; a double-click there opens one picker, not three (the second click is ignored and the double-click stops at the cell). The Keep size tick flips on click, selects its row as Tk's did, and carries the Tk tooltip; a double-click on it flips it once and then opens the picker, as Tk's Button-1 then Double-1 did. Double-click or Enter picks. Shift-click / Ctrl-click select several rows. The table is virtual and was checked with 5 803 rows.
- **Keyboard in "Group by scene"** (the ttk Treeview's own keys, `ttk::treeview::Keynav`): Right opens a group, Left closes an open group, and Left on a picture goes to its group. Up / Down / Enter come from the table.
- **Column widths** (Tk `_persist_tree_columns` / `_save_tree_columns` / `_autosize_tree_columns`): drag the grip at a heading's right edge. Only the column you dragged is saved, in settings.json `column_widths.image_web`, and from then on it keeps that width; the others keep fitting their content (the heading with room for ▲/▼, and the widest cell of the whole scan, measured in the page's own fonts), capped at 480 px as in Tk and never below the Tk tree's minwidths. Original Image and Replacement share what is left, as the design has it. Under the global zoom the saved width is converted to CSS pixels. Tk's own `column_widths.image` is left alone and not read: those are Tk pixels for another font, on a table with no thumbnail column (the Audio port's rule; David's saved Tk widths would add up wider than the window at 1210 px and leave no Replacement column).
- **Pickers**: one at a time. A pick, group pick, Replace from folder or Export CSV asked for while one of the tab's pickers is open answers "cancelled" (Tk's pickers were modal and took the grab; here the loop keeps turning under an open picker).
- **Row menus**: they are built in Python with Tk's rules and labels:
  - a slot: Choose replacement…, Clear replacement, Open in Fonts window…, Show scene contents…, the OS reveal label, and Find in Partition Explorer (through `partitions.find_in_partition`);
  - a group: Assign replacement to all N images…, Blank all N images (transparent)…, Clear replacements in group, Rename group…;
  - a multi-row selection: "N slots selected", then Clear N replacements in this selection.
- **Picking**: the file picker ("Choose a replacement for <rel>", Image files filter from `REPLACEMENT_EXTS`, remembered folder). The group picker. Blank uses `.blank.png` in the folder. Rename group uses a page modal with Tk's prompt; the current name opens selected, so typing replaces it (Tk `_ask_text`). It trims to 50 characters, and a blank name restores the generic one. It is mirrored to `tag_library`, and a fresh folder is seeded from it.
- **Fonts… and Scenes…**: the buttons and the row-menu entries ("Open in Fonts window…" on a glyph, "Show scene contents…" on a glyph, Radium picture or scene texture) check for a project first, then open the real windows through `window.open_font_studio(assets, preselect_rel=)` / `window.open_scene_browser(assets, preselect_rel=)` (the Text service's windows, drawn by the shell over any tab). A glyph opens Fonts on the font that owns it, and Scenes on its atlas's scene; a picture opens Scenes on the scene that draws it. Double-clicking a picture in Scenes lands on its row here (`reveal_image_slot`, filters cleared), and the Scenes window steps aside itself, which covers Tk's `_step_aside_for_jump`.
- **Clearing** (PAD-142): one row, a selection (with a confirm for more than one), the whole tab (with a confirm, or "Nothing is picked…"), and a group. An applied pick gets the card's original put back from `.orig`. The log lines are Tk's.
- **Replace from folder…**: `folder_match.match_folder`. It refuses a folder inside the project, adds the fingerprint note, confirms with a summary, and logs what was left out.
- **Preview**: Original | Replacement side by side, drawn by the Tk panes' own renderer (`core.image.thumbnail_png`, checkerboard behind transparency, whole-number upscaling of small glyphs) at the pane's on-screen size. The Original pane:
  - uses the `.orig` snapshot for a changed slot;
  - says "Current file (already modified)" when there is no snapshot;
  - notes "shared by N scenes (replacing it changes all of them)".
  The Replacement pane shows the on-disk replacement for a changed slot with a snapshot. A group row previews its first shown child. Choose… and Clear replacement buttons are in the pane header (from the design). The two pictures are sized against the page's own height (so an open log drawer shrinks them, not the window height), and they stay level whether or not the "shared by" note or the keep row shows.
- **Keep this picture's own size** row (PAD-154/158/179): both sizes in Tk's three wordings, sized against the snapshot when one exists. It sits right under the Replacement heading, so it shows whenever the preview does (Tk re-tuned the tab height so a row appearing later got room; under the preview it fell below the status bar at 1440x900 with the log open). It is saved to `image_keep_size` and reaches the build through `pending_image_assignments()[2]`.
- **Short windows**: the card never shrinks below its content, so the page scrolls with it whole, as the Tk tab did. The list keeps five rows, three on a very short page (1024x700 with the log open), so the preview headings and keep row still show. Measured: 1440x900 with the log open fits with no scroll; 1210x1209 (David's saved size) fits and the list takes the rest.
- **Per-manufacturer image note**: `mfr.image_note()` shows under the card only when it is not empty (Stern returns "", so none shows today).
- **Sidecar**: the image sections (`image`, `image_keep_size`, the three view filters, `image_group_tags`, `replacement_names`), `history_log` diffs, and `on_folder_state_written`. Other tabs' sections are re-read and written back untouched. The dropped-pick log lines are included. The "Relink moved files…" hint shows once per folder across tabs (the shared `window._relink_hint_for`, as in Tk).
- **Exports and fan-outs**:
  - `pending_image_assignments` (the Write build's read), `reveal_image_slot` (Scene Browser jump), and the Tk variable names (`image_search_var`, `image_source_filter_var`, `image_change_filter_var`, `image_group_by_scene_var`, `image_keep_size_var`, `image_status_var`);
  - `invalidate_asset_scans`, `reload_assets_tabs`, `refresh_after_revert`, `clear_replace_assignments` (the image part plus the idempotent sidecar wipe that keeps what Revert all keeps), and `replacement_folder_mismatches` (with the remembered folder after an invalidate);
  - `apply_manufacturer` gives a clean slate.
- **New: Export CSV**. The Tk Images tab had none; the task asked for it. It copies Audio's: the file is `image_slots.csv` with columns Original Image, Resolution, Format, Source, Replacement, Changed On Disk, Keep Size.

## Core requests

Done: 1. a failing `compat._Var` trace is logged and the others still run; 2. the Fonts and Scenes windows are the Text service's, drawn by the shell for every tab.

Open (framework code, `js/core/ui.js` and `js/core/dialogs.js`):

3. `Table` column drag under the global zoom: `startResize` takes the columns' `getBoundingClientRect()` widths (on-screen pixels) and sets them as CSS pixels, so at 150% every column jumps 1.5 times wider the moment a drag starts, and `onResize` reports on-screen pixels. This tab converts what it saves back to CSS pixels (checked at 150%: a 60 px drag on Format saved 120, shown at 180 on screen), but the jump during the drag is the table's. Dividing `w0` and the mouse delta by the zoom (as `audio.js` does) fixes it for every tab.
4. An orphaned tooltip: `tip()` hides only on mouseleave / blur, so a tip whose anchor unmounts under the pointer (the Scenes window's (i) "Behind" badge, closed with Escape) stays over the Images tab until another tip replaces it. Tk's tip was a child Toplevel of its widget and went with it. Proposed: remember the anchor in `showTip` and hide when `!anchor.isConnected` (a rAF check while shown), and on Escape.
5. `PromptModal` (`compat.simpledialog.askstring`) opens with the caret after the initial text. Tk's `_ask_text` selected it (`entry.selection_range(0, END)`), so typing replaced it. This tab's own rename modal now selects it; the shared prompt should too.
