# bleletest.sh cases: "<owner> [p<prio>] [ev] <command>", one per line, run in order.
# Owner 538 and the orange --lts 224 sweep are what tesla strike's award handler
# (0x1cbd2c) passes; the --remove line is a guess at the "off" to be judged.
#
# What the earlier runs learned, so these are not run again:
#   run 6, plain (priority 0): all four returned 1, none moved the LEDs past the noise.
#   run 7, p255 (the group's priority byte, 0x3c14d4): the same.
# `ev` is what is left: the light system tags every group and effect with the CURRENT
# event (`0x7b7e84`), which is null from a tick hook, while tesla's handler runs inside
# a live show. With `ev` the probe makes a live show event current for the call and takes
# that show's lamp priority from 0x4f3740, exactly as tesla's handler does.
538 ev blele --sweep 0 --lts 224 --red 255 --green 140 --blue 55 --freq 10 --use_alpha 1 --alpha 255
538 ev blele --remove --lts 224
