# Every installer bundles these (installer/build.ps1 into the embedded

#

#            pyobjc frameworks it needs on darwin).
#   Linux    pywebview's Qt backend with Qt WebEngine (PySide6), so the AppImage
#            carries its own browser engine instead of needing webkit2gtk.
#
# The tests workflow does not install this file: nothing in the suite opens a
# window.  If the web view cannot start, the app opens the same page in the
# system browser and says why in the log.
