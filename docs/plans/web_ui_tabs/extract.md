# Extract tab (web UI port)

Files: `pinball_decryptor/webui/tabs/extract.py` (service), `pinball_decryptor/webui/extract_helpers.py` (pure helpers ported from Tk GUI modules), `pinball_decryptor/webui/static/js/tabs/extract.js`, `pinball_decryptor/webui/static/css/tabs/extract.css`, `tests/test_webui_extract.py`.

Source of truth: `gui/main_window.py` `_build_extract_tab` and everything it wires (apply_manufacturer's Extract part, inputs/badges/drives/deltas/admin/FDA, gating/card identity, detection, Image Info / Project Info, live DMD + switch matrix), `gui/read_card_dialog.py`, and `app.py` `_start_extract` / `_start_direct_ssd_extract` / `_start_read_card` / `_on_project_folder_picked`.

## Layout (the design, Extract.html)

Page head "Extract" + a "Recent projects" menu. Two columns (`cols c75`, stacks below 1020 px): left the **Source** card (source toggle in its header, input or card rows, project folder, every per-manufacturer option, Extract / Cancel in its footer) and, for PinMAME plugins, the **Live DMD (PinMAME)** card with the switch matrix; right **This project** (the Project Info stats, always visible, plus jumps to the Replace / Write tabs and Open folder) and **Recent projects**. Image Info and Project Info are floating, non-modal windows (Tk Toplevels without a grab); Save card as image is a page modal.

## Ported (by Tk section)

- Source toggle (direct_ssd plugins: Stern Spike 2, JJP, DP): per-manufacturer labels (`extract_iso_label` / `extract_ssd_label`), values "iso"/"ssd" as Tk; hidden and forced to "iso" elsewhere. Flips the phase ladder (direct-SSD tuple) and the gate.
- Input row: per-manufacturer noun (`extract_input_label`, else the primary extension, else "Input"), recent-paths dropdown (the shell's `path_history["extract_input"]`, picked entries go through `resolve_mapped_drive`), UNC rewrite on leaving the box, the i badge (Image Info), Browse… ("Select input file", the plugin's InputSpec filter, native separators). Input mirrors into the Write tab's Original (one-way, as Tk).
- Detection (on a worker, bump counter): happy path goes to `on_detected_game_change` (title bar) AND a chip row on the tab (caption, file size, era); warnings "Not recognised as X", "Looks like G (M) — click to switch" (switches manufacturer, keeps the path), "Matches multiple manufacturers: …", "Extract only — this format has no Write/Replace support."; the Stern era auto-switch (`set_era` + `apply_manufacturer(reset_era=False)` + prereq recheck); audio-export support drops "Extract audio" from the ladder and hides the auto-name options.
- Card row (card mode): the drive list keeps the card's width (the Refresh / Save card as image… buttons share its line only when there is room for both, else they wrap under it, as Tk's combobox took the row's slack), and when the list is still too narrow to show the picked drive's whole name, that name is printed in full under it (its size, letter and `\\.\PHYSICALDRIVEn` are what tell cards apart); drive list enumerated on a worker ("Detecting drives…", "(no drives found — click Refresh)" + the red log line, best-match auto-pick with the "Selected SSD: …" log lines, too-large drives hidden with the log line), Refresh, the card i badge (Image Info on the raw device, `identify_card` plugins), "Save card as image…" (`read_card_image` + `on_read_card`), the card identity line ("Card: …", "Reading the card…", "Card: needs Administrator to read — see below", "Card: not recognised as a X card"), the red safety line (`direct_safety_text`), the ADMINISTRATOR panel (Windows, not admin; collapsible, persisted through `on_admin_warning_collapsed_change`), the macOS FULL DISK ACCESS panel (Hide this notice → `on_fda_acknowledge`; `acknowledge_macos_fda` from the run logic).
- Drop zone (design): a dropped file becomes the input, a folder the project folder, via `extract.drop_paths`, reading the `pywebviewFullPath` the desktop host's drop handler adds.
- Project Folder row: tooltip, i badge (Project Info modal; "No project folder" box), Browse… ("Select project folder"; "Use parent folder?" when a subfolder of an extract is picked; then `on_project_folder_picked` = anchored-project auto-load with the app's own manufacturer-switch / archived-hydrate questions). Mirrors into the shared assets folder (`write_assets_var`). A hint under the box says when the folder already holds an extract (overwrite confirm), is archived (hydrate), or does not exist yet (Extract creates it) — wording from the Tk help text.
- Dutch Pinball: "Optional: updates to merge on top" with `chain_deltas_help`, Add updates... (multi-select), Clear, the summary line; hidden (and cleared) when `chain_deltas_applies` says no (AAIW). Decode DMD / DMD shader checkbox with `decode_dmd_label_for(input)`, hidden (and off) when `decode_dmd_applies` says no.
- JJP: Graphics / Sounds / File System filters; the HASP dongle checkbox (reset off on every manufacturer switch; swaps in `dongle_extract_phases`).
- PinMAME capture (Williams, Data East, Sega, Stern Whitestar): Basic extract (hidden for capture-primary, which forces capture on), Use PinMAME runtime capture, Duration (s), Simulate gameplay (hidden for capture-primary), the help paragraph in all five variants (red for "Tick at least one box…"). Phase ladder follows Basic/Capture (combined / capture / extract tuples).
- Live DMD: `on_dmd_frame` stashes the latest frame (capture thread), a 50 ms loop pump renders it to a PNG data URL (amber LUT, `extract_helpers.render_dmd_png`) and the page scales it with `image-rendering: pixelated`; `reset_dmd_preview` clears and starts the pump; the last frame stays after the run.
- Switch matrix: `on_capture_ready(fn, script)` builds the named + unlabeled WPC positions (same title, labels, tooltips); a button fires `fn(sw, 120)`; a failure logs "manual press sw#N (label) failed: …".
- Categories (Stern Spike 2): Audio / Video / Images / Text with the Tk tooltips; unticking Audio greys the naming options.
- Naming (Tk "Options:" row): Auto-name call-outs / Auto-name music / Length-prefix names with the Tk tooltips; shown per capability + audio support + Basic extract, hidden means off.
- Options persistence: `get_extract_options` / `set_extract_options` exactly as Tk (auto-name, categories, JJP filters).
- Extract button: primary "Extract"; disabled with the Tk reason shown next to it (not only as a tooltip): admin > input ("Pick a Card image to extract first." / "Select the SD card to read from first.") > "Choose an output folder first."; this tab's run → red "Cancel" (tooltip text from Tk) → "Cancelling…" (shell `cancelling`); another tab's run → disabled "Extract" with "Another operation is running — cancel it or let it finish first."
- Image Info window: a floating window with no scrim (the tab stays usable under it: change the input, start or cancel a run), dragged by its title bar, resized from its corner, kept on screen with its footer reachable, its spot remembered per viewer (localStorage, optional); an i badge re-points the open window (Tk's singleton). Path, sections from `core.image_info.collect` (worker, bump counter, "Reading image…"), Refresh, Copy Report (`as_text` → clipboard event, "Report copied to clipboard."), Close (and Escape while it has focus); closed on manufacturer switch; "No image selected" / "File not found" boxes.
- Project Info: the same kind of floating window, `_collect_project_stats` rows (Audio / Video / Images / Other files / Total / Changed / Project started), Close / Escape. The "This project" card adds "Game" and "Extracted" (date + source image name from `.extract_source.json`). Game is the PROJECT's: the image its `.extract_source.json` records (else the anchor's `stock_image`), detected by the anchor's manufacturer (else the current one) and captioned with `title_caption` on the stats worker (cached per file signature; a raw device is never probed); no row when that image is gone. It never reads the Extract input box.
- Recent projects: the card lists the registry's last 8 (name, manufacturer, date); the page-head menu names each as "name · manufacturer" with the full path dim under it (Tk's "name    (path)" label) and no hover tip; the current project's highlight and check mark follow the Project folder box as it is typed, browsed, dropped or cleared.
- Save card as image (read_card_dialog.py): heading, description, Read from (drives on a worker, auto-pick, Refresh), Save to (suggested name beside the project folder that follows the picked card until the user names it; Browse… "Save the card image as…"), the size / free-space readout (✓ fits / ⚠ won't fit), the whole-card note, the admin note, Start / Cancel; the checks "No card picked", "No image file", "Folder not found", "Replace file?", "Same drive"; "Busy" when a run is in flight; Start hands (device, path) to `on_read_card`.
- `_on_input_source_change("write")` is forwarded to the Write service's own handler (with or without the mode argument).
- Exports: every `extract_*` var the run logic reads (incl. `extract_drive_display_var`, `extract_partition_override_var`), `capture_*`, `static_extract_var`, `decode_dmd_var`, `transcribe_var`, `music_id_var`, `duration_names_var`, `extract_delta_paths`, `_extract_category_vars`, get/set_extract_options, `_refresh_extract_phases`, `acknowledge_macos_fda`, `reset_dmd_preview`, `on_dmd_frame`, `on_capture_ready`, `_on_input_source_change`; for the Write tab's copies of the card panels: `_fda_acknowledged`, `_dismiss_macos_fda_banner`, `_admin_body_text`, `_admin_warning_collapsed`, `_toggle_admin_warning` (and `extract.fda_ack` in the store).

Deliberate differences (no capability lost):
- Card mode gates Extract on the picked drive's DEVICE path, not the drop-down's text, so "Detecting drives…" no longer counts as a pick (the reason is shown instead).
- The drive row's label uses the manufacturer's medium noun ("SD card" for Stern) where Tk said "Game SSD" for everyone; JJP/DP still read "Game SSD".
- Detection, the stats walk and the probes run on worker threads (Tk ran detection on its UI thread).
- The i badges are the shared `InfoBadge` (with `onClick`); cross-tab mirrors (`write_upd_var`, `write_assets_var`) are plain sets, since compat logs a failing trace and carries on as Tk did.

## Owed

- Drag and drop from the desktop: the host's drop handler hands the page the dropped file's full path, but a real drop from Explorer was not exercised (Playwright cannot drop a desktop file). In the system browser (`--browser`) a drop shows "This window can't see where a dropped file lives — use Browse… instead."
- The floating Image Info / Project Info windows live on the Extract page: switching tabs hides them and coming back shows them again where they were (Tk's Toplevels stayed on screen over any tab). Keeping one open over another tab would need the shell to render it, as it does the Fonts and Scenes windows.
- Not verified end to end: a direct card/SSD extract and a real card read (not elevated, and never pointed at a card by rule), a live PinMAME capture (DMD frames and switch presses were exercised with fake frames / a fake press function in the tests), a full Stern Spike 2 extract (only a small Williams ROM was extracted, into a scratch folder).
- The Settings menu's "Manage disk space…" (gui/disk_dialog.py) is the Settings menu's, ported by the shell extras (`webui/shellx_disk.py`), not here.

## Core requests

None open. The three this port raised are in the framework now: the host's drop handler (`pywebviewFullPath`), compat logging a failing Var trace instead of raising it into the setter, and `InfoBadge onClick`; the tab uses all three.
