# Partitions + Compare tabs (ns `partitions`, `compare`)

Tk sources: `gui/main_window.py` `_build_partition_tab` + `_pex_*` (Partition Explorer) and `_build_compare_tab` + `_compare_*`; `app.py` `_on_partition_image_opened`, `_on_compare_run`, `_on_compare_row_limit_change`, `_start_extract_both`.

Files: `webui/tabs/partitions.py`, `webui/tabs/compare.py`, `static/js/tabs/partitions.js`, `static/js/tabs/compare.js`, `static/css/tabs/partitions.css`, `static/css/tabs/compare.css`, `tests/test_webui_partitions.py` (both tabs).

Both tabs show only when the plugin advertises `partition_explorer` / `compare`: Stern Spike 2 today (hidden for Spike 1, Whitestar and every other manufacturer).

## Ported (by Tk section)

### Partitions
- Intro paragraph: page subtitle (first sentence) + the whole Tk paragraph in the (i) badge.
- Card Image row: path field (Enter opens), Recent menu (this manufacturer's `partition_image` history; picking one opens it), Browse… ("Select a card image", Card image *.raw *.img *.bin / All files). A mapped drive letter is resolved to UNC when the image is opened (Tk did it on focus-out).
- Blank Card Image defaults to the Extract tab's .raw/.img/.bin input on tab entry and opens it (`on_show`), never overriding a typed path.
- Open: "Extract in progress" / "File not found" / "Not a card image" / "Nothing to browse" dialogs, log lines, `on_partition_image_opened` (recent paths + settings save).
- Partition list: `sda<N> — <label> (<size>)` + ` — not browsable`, first browsable pre-selected; non-browsable pick = status line; mid-extract changes snap back.
- Show: All / Changed / Unchanged (segmented, with the Tk tooltip), built from `core.card_edits` exactly as Tk (Changed = journal-only tree fully open with count status; Unchanged = replaced files left out as folders load; missing file = Type "not on the card now").
- Find + Find Next: whole-partition path walk cached per image+partition, cycles, resets Show to All, expands down to the hit and selects it, "No file path contains “…”." status. Works while an extract runs (the Tk button had no busy check). The hit is scrolled wholly into view below the sticky header with a row of context under it (Tk `see()`).
- Tree: lazy ext4 tree as a virtual table (Name with expander + indentation, Size, Type incl. `symlink → target`, Changed); a replaced file's WHOLE row is in the warning colour (Tk tag `pex_changed`), with "not on the card now" in red. Click selects, double-click expands / collapses. The stock ttk.Treeview keys: Up / Down move, Enter and Space open / close a folder, Right opens a folder, Left closes an open folder that has rows under it and otherwise goes to the parent folder. Column widths drag from the header edges (every ttk header did); kept for the session, not saved (Tk never saved this tree's widths); once dragged, Changed takes what is left.
- The tree stays usable while an extract (or a Replace) runs, as in Tk: the busy indicator is a small pill in the middle of the tree that never takes a click (Tk placed a spinner label there), so rows can be selected, previewed, expanded, found and right-clicked for Properties… / Copy path under and around it.
- Preview: text (256 KB cap, UTF-8, binary detection and every Tk placeholder string), images/fonts rendered on a worker with the 12 MB cap and a sequence number, caption "PNG · 1360 × 768 · 162.1 KB"; the picture is written to a temp PNG and served through `/media`, sized to the preview box (grows with the window; the Tk canvas was fixed 330x250). Text preview scrolls both ways.
- Context menu (right-click): Properties…, Copy path, Extract…, Replace with… (files only). While busy only Properties… and Copy path are offered (Tk). Properties and Replace with… are also buttons under the preview for the selected row.
- Properties: a modal with Name / Kind / Size / Partition / Path / Mounted at (copy buttons on the two paths) and one Replaced line per journaled swap with its source; folder size computed on a worker with "Sizing <name>…".
- The status line sits on the buttons' row and ellipsizes (full text on hover) instead of wrapping under them, so the tree never changes height when a status comes or goes (Tk packed it beside the buttons).
- Extract Selected (file: "Extract file as…" save; folder: "Choose a folder to extract this directory into"), Extract Whole Partition (lands under `sdaN`), Extract All Partitions (one `sdaN` each); worker on a fresh CardImage with live Cancel (the launching button turns into Cancel, then "Cancelling…"), overlay "Extracting…  12 files (3.4 MB)" / "4.0 MB / 12.9 MB", result in the inline status + log, "Extract cancelled — partial files may remain.", "Extract failed: …" (error level).
- Replace with…: "Replace <name>" picker, "Replace on card" warning yes/no with the same-size vs grow/shrink (WSL2) wording, worker with "Replacing…" overlay and no cancel, ext4 driver log lines, journal written BEFORE reopening, extract-staleness verdict in the log, image re-opened, result kept in the status line.
- Find in Partition Explorer (the Replace tabs' deep link): `window._asset_find_in_partition(kind, rel, assets_dir=None)` (also `find_in_partition`) with every Tk dialog and log line.

### Compare
- Intro: subtitle + (i) badge with the Tk paragraph.
- Image A / Image B rows: path field (Enter runs Compare), Recent menu (`compare_a` / `compare_b` history), Browse… ("Select card image", the manufacturer's input file types, starting in the field's folder or the Extract input's).
- Compare: "Pick two images" / "File not found" checks, `on_compare_run` (recent paths + settings), extract roots exactly as Tk (Extract Both parent, Extract output and parent, project folder, each card's folder), `mfr.compare_images` on a worker with a sequence counter; an exception becomes the "Error" section; overlay "Comparing images…".
- Report: section rows (collapsible, plus Collapse all / Expand all), head rows coloured by kind (Added / Modified / Deleted …), item rows, openable file rows in the link colour; "… and N more — double-click to list them" expands only that group (double-click or click); the whole report stays in memory. A selected row never carries over into a different report (the service counts reports in `report`; Tk's repaint deleted every item). The Change column's width drags from its header edge (session only, as in Tk).
- Rows per list: 12 / 25 / 50 / 100 / All, default 50, restored from `compare_row_limit`, persisted through `on_compare_row_limit_change`, repaint only.
- Copy Report: `image_info.as_text(..., "Compare Report")`, every row, clipboard via the shell's clipboard event, status line.
- Double-click a file row: the ref's side picks the card, "Image X is no longer at" error, `mfr.extract_report_file` into a temp folder on a worker (one at a time), `desktop.open_path`, "Opening … / Opened … from image X." status, both failure dialogs; a non-file row says "Only the listed files open …".
- Extract Both: "Pick two images" / "File not found" / "Same image twice" checks, then the run logic's `on_extract_both` (folder dialog, switch to Extract, chained run). Its hover tip is hidden on the click and whenever the Compare page goes away, so it never floats over the Extract tab (Tk sent `<Leave>` when the tab unmapped).
- Manufacturer switch resets the report and orphans an in-flight run.

## Owed
- Nothing functional known.
- Differences by design (no lost function): Show rebuilds the tree while an extract runs (Tk ignored the pick until the extract ended, because its rebuild re-enabled the extract buttons; here the buttons follow `busy`), and a Find mid-extract therefore really drops back to All; during a Replace a Show pick still waits for the re-open that ends it. The Tk braille spinner is a CSS spinner; the three Extract buttons use one accent (Extract Selected) instead of three green buttons; the recent-paths dropdowns are a menu button next to each path field; the "Find:" label is the search box's placeholder + icon; a mapped drive letter is resolved to UNC when the path is USED (open / Compare / Extract Both) rather than on focus-out.
- Kept from Tk on purpose: the Extract Selected log line says "from partition <0-based index>" while every label says sdaN (a known Tk inconsistency; wording kept).

## Core requests
- `ui.js` `tip()`: hide the tooltip on a click of its target and when its element unmounts (a tab switch under a still pointer leaves it floating). Both tabs work around it by hiding `body > .tip` on unmount (and Compare on the Extract Both click).
- `ui.js` `Table`: its scroll-into-view ignores the sticky header's height, and the stock `.tbl .tr { min-height: 34px }` makes rows taller than any `rowHeight` below 34 so each row overlaps the next (audio 32, text / fonts / scenes 30 still do). Both tabs set `min-height: 0` on their body rows and Partitions keeps the selected row in view itself.
- Otherwise none required.  Cross-tab API for the Replace tabs' "Find in Partition Explorer": call `self.window._asset_find_in_partition(kind, rel, assets_dir)` (kind "audio" / "video" / "image", assets_dir = that tab's scanned folder).
